## [0.1.0] - 2026-09-10

### Added

- Framework-free image gallery with local and persisted image support.
- Drag-and-drop, pointer and keyboard reordering.
- Primary-image selection, alternative text editing and 90-degree rotation.
- Asynchronous persisted-image deletion with accessible confirmation.
- Native form integration with manifest and keyed file serialization.
- WebP conversion, dimension limits and file-size validation.
- English and Brazilian Portuguese locales.
- ESM, global IIFE and standalone CSS builds.
